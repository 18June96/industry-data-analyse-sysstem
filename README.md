# 申万行业数据分析系统技术文档
## 一、项目概述
　　本系统是一个基于 Streamlit 框架构建的金融数据分析与可视化平台。系统主要针对申万一级行业进行深度分析，集成了数据清洗、财务综合评价（PCA模型）、收益率计算及可视化展示等功能。该平台旨在帮助用户通过交互式界面，快速了解特定行业的指数走势、成分股表现，并基于财务数据对行业内公司进行量化排名和投资组合收益回测。
## 二、技术栈
　　前端框架: Streamlit (用于构建 Web 交互界面)  
　　数据处理: Pandas, NumPy  
　　可视化: Matplotlib (用于绘制折线图)  
　　机器学习/统计: Scikit-learn (StandardScaler, PCA)

## 四、核心模块详解  
系统主要由三个核心函数构成，分别负责数据处理、模型计算和界面渲染。  
### 4.1 数据处理模块 (st_data)  
**功能:** 负责加载数据、筛选特定行业数据并生成可视化图表。  
输入: nm (行业名称), info (行业分类表)  
处理流程:  
　　1.数据加载: 读取指数、个股、财务及基本信息表；  
　　2.行业筛选: 从指数表中筛选出指定行业的数据，并检查数据量是否大于 600 条；  
　　3.图表绘制:  
　　　　图1 (f1): 绘制该行业的收盘指数走势图。  
　　　　图2 (f2): 绘制行业内交易记录大于 600 条的前 6 只个股的价格走势图（3x2 子图）。  
　　4.数据关联: 利用行业分类表关联出该行业内的所有成分股，并合并对应的交易和财务数据。  
输出: 返回图表对象及处理后的 DataFrame。  
### 4.2 综合评价模块 (Fr)  
**功能:** 基于财务数据对上市公司进行多维度综合打分（使用 PCA 算法）。  
算法流程:  
　　1.数据筛选: 筛选指定年度的财务数据；  
　　2.数据清洗: 过滤负值和空值；  
　　3.标准化: 使用 StandardScaler 对财务指标进行标准化处理；  
　　4.降维分析: 应用 PCA (主成分分析)，设置累计贡献率为 95%，提取主要成分；  
　　5.综合得分计算: 根据主成分得分和贡献率加权求和，计算出最终的综合得分F；  
　　6.结果合并: 关联股票代码和简称，按得分降序排列。  
输出: 包含股票代码、简称及综合得分的排名表。  
### 4.3 收益率计算模块 (Tr)  
**功能:** 计算投资组合在特定持有期内的收益率，并与沪深300指数进行对比。  
输入: 综合排名结果、组合数量、开始日期、结束日期。  
处理逻辑:  
　　1.数据合并: 读取 2023-2025 年的复权交易数据；  
　　2.个股收益: 遍历排名前 N 的股票，计算其在持有期初和期末的涨跌幅；  
　　3.组合收益: 计算所选股票的平均收益率；  
　　4.基准收益: 读取沪深300指数数据，计算同期的指数收益率；  
输出: 单只股票收益率表、组合总收益率、沪深300收益率。  
### 4.4 界面展示模块 (st_fig)
**功能:** 构建 Streamlit 交互式界面。   
布局:  
　　侧边栏: 包含行业选择器、评价年度、投资组合数量及持有期日期选择器。  
　　主区域:  
　　　　图表区: 并排展示行业指数图和个股走势图。  
　　　　数据折叠区: 使用 expander 折叠展示各类原始数据表（指数、财务、交易等）。  
　　　　评价结果区: 展示财务综合得分排名，并绘制前 N 名的得分折线图。  
　　　　收益率分析区: 展示投资组合的收益表现及基准对比（使用 st.metric 突出显示）。

## 六、注意事项  
　　文件路径: 代码中使用了相对路径。如果文件不在同一目录，需要修改 pd.read_csv 和 pd.read_excel 中的路径。  
　　数据完整性: 如果财务数据或交易数据缺失，系统会通过 st.warning 或 st.error 在前端提示用户。  
　　性能优化: 由于每次交互都会重新计算 PCA 和读取文件，对于大文件可能会有延迟。建议在生产环境中使用 @st.cache_data 装饰器缓存数据读取和计算结果。  
　　日期格式: 代码中对日期进行了格式化处理（如 strftime('%Y%m%d')），请确保数据源中的日期格式与此兼容。  
## 七、总结
　　该代码是一个结构清晰、功能完整的金融量化分析工具。它不仅实现了数据的可视化展示，还结合了统计学模型（PCA）进行智能选股和收益回测，非常适合用于金融数据分析的教学演示或初步的行业研究。
